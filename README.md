# ⚔️ SURVIVOR: TIME ATTACK

> 생성되는 적들을 처치하고 끝까지 살아남는 액션 생존 게임입니다.  
> 공격 범위와 적의 숫자를 확인하고 적의 치명적인 공격을 회피하세요!

---

## 🎮 게임 설명

### 1단계: 게임 시작
#### 버튼을 눌러 게임을 실행합니다.

---

### 2단계: 적 스폰 및 생존
#### 게임이 시작되면 사방에서 적들이 생성되어 플레이어를 추격합니다.
* 플레이어는 적들의 충돌 데미지를 피해 살아남아야 합니다.

---

### 3단계: 적 공격 예고 (핵심 시스템)
#### 플레이어가 공격 상태에 돌입하면 색상이 바뀌고 바닥에 공격 범위가 표시됩니다.
* 공격 쿨타임이 있으며, 시간 내에 다시 사용할 수 없습니다.
---

### 4단계: 피격 및 게임 오버
#### 적의 공격에 맞으면 체력을 잃고 적은 소멸합니다
* 범위 내에 있을 경우 큰 피해를 입으며, 플레이어의 체력이 0이 되면 게임 오버가 됩니다.

## 🛠 사용 기술

* Python 3
* Pygame
